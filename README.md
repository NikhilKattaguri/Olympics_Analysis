# Olympics Data Analysis using SQL  
Performed comprehensive SQL-based analysis on **120 years of Olympic history**, uncovering trends in participation, medal performance, athlete demographics, and sport evolution using the `athlete_events` and `noc_regions` datasets.

---

## 📊 Project Overview
This project explores the **modern Olympic Games dataset** using SQL to answer 20 real-world analytical questions.  
The analysis covers:

- Participation trends  
- Medal performance by athletes and countries  
- Gender distribution  
- Sport-level insights  
- India’s Olympic performance  
- Historical comparisons across all Olympic editions  

The project demonstrates strong SQL skills including **joins, CTEs, window functions, ranking, conditional logic, and grouping techniques**.

---

## 📁 Dataset Information
### **1. athlete_events.csv**
Contains athlete-level participation records.

- **Rows:** 271,116  
- **Columns:** 15  
- Includes: Name, Sex, Age, Height, Weight, Team, NOC, Games, Year, Season, City, Sport, Event, Medal  

### **2. noc_regions.csv**
Maps NOC codes to country/region names.

- **Columns:** NOC, Region, Notes

## 📈 Analytical Approach
The project answers **20 structured SQL questions**, covering:

- Counting distinct Olympic Games  
- Participation analysis by year and country  
- Identifying countries with full participation  
- Gender ratio analysis  
- Top athletes by gold and total medals  
- Sports played in all Summer Olympics  
- Sports played only once  
- Medal breakdown by country and Olympic edition  
- Ranking countries using window functions  
- India’s medal performance by sport and event  

Advanced SQL concepts used:

- **JOINs**  
- **GROUP BY & HAVING**  
- **DISTINCT aggregation**  
- **CTEs**  
- **DENSE_RANK() window function**  
- **Conditional aggregation (CASE WHEN)**  

---

## 🏅 Key Insights Generated
- Total number of Olympic Games held  
- Countries that participated in every Olympic edition  
- Oldest athlete to win a gold medal  
- Sports consistently played across all Summer Olympics  
- Countries with medals but no gold  
- India’s strongest Olympic sport (Hockey)  
- Medal leaders (Gold/Silver/Bronze/Overall) for each Olympic Games

## ⚠️ Dataset Limitations
- Missing values for age, height, weight  
- Medal counts may include team events  
- Dataset ends at **2016 Rio Olympics**  
- Some NOC-to-region mappings are historical or ambiguous
